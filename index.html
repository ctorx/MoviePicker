One-time setup

This app uses TMDB, a free movie database. You need a free API key:

  1. Create a free account at themoviedb.org/signup
  2. Go to Settings → API and request a key (choose "Developer", any app name works)
  3. Paste the API Key (or the long "Read Access Token") below

The key is stored only on this device.
